# Atlas-Diagnostics

> Sistema web de diagnóstico sistémico e gestão de sessões para acompanhamento de pacientes, desenvolvido em **Python (Flask)** com arquitetura **Local-First** e persistência segura em JSON.

---

## 🚀 Sobre o Projeto
O **Atlas-Diagnostics** foi desenhado para fornecer uma ferramenta limpa, rápida e altamente privada para profissionais gerirem sessões e avaliações baseadas em múltiplos pilares de equilíbrio estrutural. Os dados de cada utilizador são encriptados e armazenados de forma isolada, garantindo total confidencialidade.

## 🛠️ Tecnologias Utilizadas
* **Backend:** Python / Flask
* **Frontend:** HTML5, CSS3 (Design Responsivo com Tema Escuro e Dourado) / JavaScript (Vanilla)
* **Segurança:** Hash SHA-256 para passwords, proteção contra *autofill* e limpeza automática de memória de sessão.
* **Armazenamento:** JSON local estruturado por utilizador.
